# 哈吉咪 GIF 角色素材 v1

按用户提供的橘猫参考图生成，使用内置 **image_gen** 制作动作帧，FFmpeg 切帧、对齐脚底与编码。没有使用原来的 SVG 角色代替生图。

| 文件 | 内容 | 格式 |
| --- | --- | --- |
| `warn.gif` | 偏头、斜眼、短暂眯眼 | 512×512，8 帧，约 1 秒 |
| `stress.gif` | 歪头、拱背炸毛、张嘴叫板 | 512×512，16 帧，约 1.33 秒 |
| `grooming.gif` | 蹲下、抬起前爪、伸舌舔毛 | 512×512，16 帧，约 1.6 秒 |

全部为透明背景、无限循环 GIF。为避免回到首帧时突跳，较长动作采用往返帧序，并在转折处短暂停留。GIF 是单色阶透明，透明原始 PNG 帧和整张动作帧图也保留，方便后续改用 APNG / WebM。

源文件：

- `sheets/`：两张 ImageGen 原始动作帧图。
- `frames/`：切分、统一脚底位置后的透明 PNG 帧。
- `reference/character.png`：用户提供的造型、画风参考。
- `prompts.json`：完整生成提示词及工具路径说明。
- `manifest.json`：尺寸、帧数、帧率、文件体积。

验证：所有 GIF 完整解码通过；帧数与尺寸通过 ffprobe 检查；透明标志与逐帧恢复背景（disposal=2）通过 GIF 元数据检查，避免透明动画残影。

样机已在正常、预警、炸毛、舔毛阶段使用这套栅格角色；正常状态采用第一张站姿，打架烟雾仍使用现有动画。

复现 GIF 编码：在项目根目录运行 `python3 scripts/build_cat_gifs.py`。
