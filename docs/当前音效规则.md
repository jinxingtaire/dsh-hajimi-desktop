# 当前音效与回血动作 · 2026-11-17

最新用户纠正：**不是越近声音越大，而是越近音调越高；此前的“吧唧嘴”实际指舔毛**。距离增益与单独吧唧嘴动作均已取消。

项目音效库只保留上述 13 条基础音效。未选素材的项目副本已移到系统废纸篓；外部原文件不受影响。

## 交互

打开声音后，常态下单击一只猫，从普通音效中随机回应，并避开紧接上一条。

两猫靠近后，偏头与炸毛两个阶段均播放不满音效：各猫有独立声源，屏幕左侧猫只进入左声道，右侧猫只进入右声道。猫换边时声道平滑跟随。每轮两种不同叫声；6 条不满叫声全部用完才重新随机，轮换后不紧接重复。两段错开约 90ms 起声，播完留短间隔，拉远约 80ms 淡出。

距离连续映射至 0–4 半音升调。两猫声源增益固定为 0.2，不随距离增加。升调使用预生成的等时长变体并平滑混合，源播放速率为 1；共享低通（4300Hz）、压缩和输出余量控制尖锐高频与峰值。

烟雾打架期间循环播放已选生气声，每对猫只建立一个循环声源；分开进入回血后约 80ms 淡出。静音、重置、打开音效面板或页面隐藏时停止循环，多对猫同时打架时各自独立。回血时低头、抬起前爪、伸舌舔毛，当前不附加未经确认的舔毛音效。
