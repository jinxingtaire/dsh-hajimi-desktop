# 哈吉咪 DSH 桌宠 v0.2.0

## 安装与启动

DSH 桌面版打开「插件 → 添加插件 → 安装第三方插件」，填入插件本地目录或 `.tgz` 路径。插件包名称为 `@dsh-external/hajimi-desktop`，通过 `cordis.patch.yml` 注册 Host 插件。启动时自动显示桌宠。

项目目录已安装开发依赖，可直接使用 `/Users/jinxing/Projects/大肥鱼` 作为本地插件来源。分发包通过 `npm run pack:plugin` 生成到 `output/`；运行时依赖 Electron 45.3.3，首次启动会从 Electron 官方发行渠道获取平台二进制。

## 操作

- 单击：随机普通喵叫。
- 拖拽：随意摆放；透明像素不会阻拦下方应用点击。
- 右键：加橘猫、加灰白虎斑、给当前猫换肤、送走当前猫、声音开关、舔毛预览、重新摆放、隐藏、关闭。
- 菜单栏猫咪图标：提供同样的全局操作；隐藏后可从这里找回。
- 多屏：菜单中选择「移动到显示器」。当前一组猫在同一个显示器内互动。

靠近时两猫分别从左右声道播放不同的不满叫声，六条用完再重新随机。距离越近音调越高（最高 +4 半音），不随距离增加增益，播放速度保持稳定。贴近后吸附、打成共同烟雾；整段烟雾期间打架音效循环，分开后停止并各自舔毛回血。

## 本机状态与生命周期

设置文件位于 `~/Library/Application Support/dsh-hajimi-desktop/desktop-state.json`。只保存猫咪位置、皮肤、桌面尺寸、声音开关，不保存会话内容。DSH 禁用/卸载插件或退出时，插件会停止桌面进程、关闭本机素材服务；进程还会检查宿主是否存在，避免遗留窗口。

安装调试前运行的独立窗口需要先退出，避免与 DSH 管理的实例争用单实例锁。插件关闭后，可在 DSH 禁用并重新启用插件来重开。

## 验证范围

- 18 项自动检查通过，包含互动状态机、音效分类与配对、桌面像素鼠标命中、状态文件字段、资源服务访问限制及取消启动清理。
- 已在 macOS 的 DSH 插件管理器验证禁用会关闭桌宠，重新启用会启动唯一一个由 DSH 托管的桌宠进程，并恢复两只猫和声音设置。
- 在 DSH 托管的桌面窗口实测了猫咪右键菜单、拖拽贴近、共用烟雾和分开舔毛。实机截图见 `output/dsh-hajimi-fight.jpg` 和 `output/dsh-hajimi-grooming.jpg`。
- 音效混音、升调和循环已通过自动检查及浏览器音频渲染验证。桌面版的实际扬声器听感待试听。
- Windows / Linux 尚未实测；多屏之间不支持直接跨屏拖动，使用菜单切换整组显示器。
- 当前不联动 DSH 任务进度或审批提醒，专注猫咪桌面互动。
