# 哈吉咪：别靠太近

DeepSeek Harness 哈吉咪桌宠插件。提供透明置顶桌面窗口、透明区域鼠标穿透、多猫拖拽、双声道应激叫声、烟雾打架与舔毛回血。由 DSH 插件管理桌面进程启停，另保留浏览器样机。

## DSH 桌面版

在 DSH「插件 → 添加插件 → 安装第三方插件」中填入本项目本地目录，或 `output/` 中的插件 `.tgz` 安装包。安装/启用后桌宠出现在主显示器；首次使用需要获取 Electron 运行时。

右键猫咪或点击菜单栏猫咪图标，可以加猫、切换皮肤、开关声音、隐藏、重新摆放或关闭桌宠。猫咪位置、皮肤、声音设置保存在本机；DSH 退出或禁用插件会关闭桌面进程。支持当前实测的 macOS；多显示器可通过菜单选择显示器，同屏猫咪会相互感知。

独立实机验证可运行 `npm run desktop`。安装、打包与已知范围见 `docs/DSH桌宠使用说明.md`。

## 运行

在当前目录运行 `npm start`，打开 http://127.0.0.1:8788 。无需安装 npm 依赖。

- 默认一只猫，点击回应，按住拖动；「再来一只」添加同伴，样机上限六只。
- 拉近：偏头 → 炸毛 → 贴近停留 → 吸附 → 烟雾打架 → 分开舔毛回血。
- 预警和炸毛阶段可以随时拖走，解除应激。回血期间允许拖走，不开启新战斗。
- Tab 聚焦猫咪，方向键移动，空格或 Enter 摸摸。
- 默认静音。打开声音后，常态单击随机播放普通猫叫。音效按用户试听结果保留 13 条：普通 6、不满 6、生气 1；「猫叫音效」可按分类试听。
- 两猫靠近时分别从左右声道播放不同的不满叫声；六条轮完再随机，拉远淡出。越近音调越高（最高 +4 半音），增益和播放速度保持稳定。
- 烟雾打架全程循环打架音效，分开进入舔毛时淡出。静音、重置和隐藏页面也会停止循环。
- 「玩法与声音 → 预览舔毛动作」可直接看回血时低头舔前爪、整理毛发。
- 猫咪已按参考图用 ImageGen 生成栅格美术：偏头、应激、舔毛使用透明循环 GIF，正常状态使用同一套站姿。素材见 `assets/pets/hajimi-v1/`。
- 新增灰白虎斑皮肤：素材见 `assets/pets/hajimi-gray-v1/`。添加猫咪时交替使用橘猫和灰白虎斑；右键或聚焦后按 S 可单独换肤。

## 文件

- `engine.mjs`：与 DSH 无关的距离判断、状态机、配对、冷却逻辑。
- `app.mjs` / `style.css` / `index.html`：可玩样机、GIF 角色状态切换、音效入口。
- `assets/pets/hajimi-v1/`：透明 GIF、PNG 源帧、角色参考与 ImageGen 完整提示词。
- `assets/audio/selection.json`：用户确认的 13 条音效分类；`manifest.json` 是运行时索引。
- `audio.mjs`：双声道混音、随机片段轮换、恒定音量与距离升调。
- `scripts/split_audio.py`：可复现的原声切分、响度处理和导出检查。
- `scripts/import_supplemental_audio.py`：只导入已选的 12 条 MP3；视频切分脚本只保留已选的连续声段 01。两者都遵守 `selection.json`。
- `scripts/curate_audio.py`：应用分类并将未选的项目音效副本移到系统废纸篓。
- `scripts/build_pitch_variants.py`：生成不满叫声的等时长升调变体，供实时平滑混合。
- `docs/当前音效规则.md`：当前分类、声道、音调与响度规则。
- `docs/玩法与DSH接入.md`：完整体验、素材清单、已核实的 DSH 社区插件能力与待验证项。
- `npm test`：检查核心互动逻辑。

插件不读取或发送 DSH 对话、模型密钥与文件内容；本机资源服务仅在 loopback 上按临时随机路径提供猫咪素材。浏览器样机与桌面版复用同一套互动和音频引擎。
